# Architecture decision records

Store durable, consequential decisions here as concise immutable records named
`NNNN-short-title.md`.

Each ADR contains: status, date, context, decision, consequences, and superseded
records. Amend factual corrections in place; change an accepted decision by
adding a new ADR that explicitly supersedes the old one.

GitHub issue and pull-request links provide discussion and implementation
evidence. `CONTEXT.md` summarizes accepted state but does not replace ADRs.
